# Decisões confirmadas do projeto

1. Nome de trabalho: Guitar Legends — Edição Lendária.
2. A proposta não será limitada a músicas de um artista ou gênero.
3. A ISO não terá uma coleção obrigatória de músicas comerciais.
4. O objetivo é permitir playlists montadas com arquivos musicais pessoais compatíveis.
5. O multiplayer inicial será para dois celulares na mesma rede Wi-Fi.
6. Qualquer jogador poderá criar a sala.
7. Os dois jogadores ouvirão a mesma faixa sincronizada.
8. Cada jogador poderá escolher sua própria dificuldade.
9. Os modos cooperativo e competitivo permanecem planejados.
10. A plataforma PS2/NetherSX2 permanece como hipótese inicial, sujeita a testes de acesso a arquivos, áudio e rede.
11. Não afirmar compatibilidade de formatos, transferência de músicas ou rede antes de validar tecnicamente.
